# Multimodal Deepfake Detection

## Установка и запуск

1. **Создание виртуального окружения и установка зависимостей**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install torch torchvision torchaudio huggingface_hub transformers opencv-python facenet-pytorch numpy Pillow
   ```

2. **Запуск**:
   ```bash
   python main.py
   ```
   *При первом запуске скрипт автоматически скачает необходимые веса моделей (TorchScript для HiddenCLIP и MobileNetV3), что может занять некоторое время*

## Архитектура

Проект разбит на слабо связанные компоненты:
* **`core/`** — Абстрактные интерфейсы (`interfaces.py`) и базовые сущности (`entities.py`). 
* **`data/`** — Модули предобработки. Отвечают за однократную загрузку видео (`VideoLoader`, использует OpenCV) и выделение лиц (`FaceTracker`, использует алгоритм `MTCNN`).
* **`modalities/`** — Независимые изолированные компоненты моделей:
  * **Spatial (`spatial.py`)**: Основан на пред-обученном **HiddenCLIP** .
  * **Temporal (`temporal.py`)**: (Заглушка, как пример реализации еще одной модальности) Анализ динамики во времени. Использует замороженный **MobileNetV3** как извлекатель визуальных признаков (feature extractor) и сеть **LSTM** для анализа их последовательности.
* **`pipeline/`** — Оркестратор (`MultimodalDeepfakeSystem`), который прогоняет данные по цепочке, и Агрегатор (`WeightedAggregator`), смешивающий предсказания по весам.

## Как работает пайплайн?

1. **Загрузка видео**: `SimpleVideoLoader` извлекает кадры с равномерным шагом (для экономии памяти, по умолчанию 16 кадров на видео).
2. **Трекинг лиц**: `DummyFaceTracker` при помощи `MTCNN` ищет главное лицо на каждом кадре, центрирует, добавляет отступы (margin) и кропает в размер $224 \times 224$. Вырезанные лица помещаются в единый объект `VideoContext`.
3. **Параллельные модальности**: 
   - *Пространственная* и *Темпоральная* модели параллельно берут из `VideoContext` кропы лиц, применяют свои специфичные трансформации (`Resize`, `Normalize`) и делают вычисления.
   - Каждая модальность возвращает объект `DetectionResult` с оценкой фейка от $0$ до $1$.
4. **Агрегация**: Все результаты комбинируются в `WeightedAggregator` и формируется итоговая вероятность фейка.

## Текущие заглушки

Элементы в виде заглушек:

1. **Необученная Темпоральная модель (LSTM)**: В файле `modalities/temporal.py` архитектура выстроена полностью (MobileNetV3 -> LSTM -> Linear -> Sigmoid). Эмбеддинги извлекаются по-настоящему, но **веса самой LSTM инициализированы случайно**. На данный момент она выдает шум/случайное значение в районе $0.5$. Эту часть сети необходимо обучить на реальном датасете.
2. **Простой Face Tracking**: Сейчас файл называется `DummyFaceTracker`. Он использует настоящий алгоритм MTCNN, однако пока **не умеет отслеживать несколько разных лиц** (Multiple Face Tracking) одновременно. Он просто берет самое крупное лицо (`select_largest=True`) и считает его единой сущностью (идентификатор `track_id=1`).
3. **Веса Агрегатора**: В `main.py` при инициализации `WeightedAggregator` используются жестко зашитые "ручные" веса (`spatial: 0.6, temporal: 0.4`). В идеале эти веса должны быть результатом обучения мета-классификатора или подбираться под конкретный тип атак.
4. **Аудио-модальность**: В структуре `VideoContext` предусмотрено поле `audio_dict`, но аудио-пайплайн пока не реализован.
